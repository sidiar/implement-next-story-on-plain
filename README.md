# implement-next-story-on-plain

A throwaway project: a tiny todo CLI (stdlib Python) whose stories are implemented by the
[implement-next-story](https://github.com/sidiar/implement-next-story) skill on its `plain`
adapter — no BMad, no framework, just `epics.md`, `sprint-status.yaml` and `python3 -m unittest`.
Each merged PR is one story run; the run's stats are at the end of its story file.
